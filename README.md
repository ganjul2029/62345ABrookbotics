# 62345ABrookbotics
Brookbotics All Season Code Uploading (ASCU)


ALL FILES/CODE MUST BE NAMED CORRECTLY & CORRECTLY CATEGORISED:

E.g. 2026-Override --> AllianceMatches:

Inside AllianceMatches folder are multiple folders:

- DriverControlOnly (DCO)
- FullControl (FC)
- AutonomousOnly (AUTON)

When labelling the file, the following format [SEASONCODE]-[FOLDERCODE]-[DD.MM.YY]-[VERSION NO. FOR THAT DAY]

VEX OVERRIDE SEASON CODE: OVR

Example for a DCO Code on the 7th of Sept: OVR-DCO-7.9.26-V1
